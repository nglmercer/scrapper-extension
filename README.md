# RAW Data Interceptor

A powerful, cross-platform WebSocket data interceptor for Chrome, Firefox, and Electron applications. Designed to capture, analyze, and process WebSocket communications in real-time.

## 📚 Documentation

- **[Getting Started](docs/getting-started.md)**: Installation, overview, and features.
- **[Platforms](docs/platforms.md)**: Specific guides for Chrome, Firefox, and Electron.
- **[Configuration](docs/configuration.md)**: How to configure the interceptor.
- **[API Reference](docs/api.md)**: Detailed API documentation and message format.
- **[Testing](docs/testing.md)**: Running tests and using the test server.
- **[Building](docs/building.md)**: Build commands and project details.

## 🚀 Quick Install

```bash
npm install raw-data-interceptor
```
